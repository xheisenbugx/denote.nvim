# Contributing to denote.nvim

Bug reports, ideas, and pull requests are welcome, especially where behaviour differs
from Emacs Denote. Please include `:checkhealth denote` output in bug reports (the issue
template asks for it).

## Development

```sh
make test                                  # all specs, headless (tests/run.lua)
make test SPEC=tests/spec/naming_spec.lua  # a single spec
make lint                                  # stylua --check
make format                                # stylua
make typecheck                             # lua-language-server --check (.luarc.json)
make bench N=10000                         # time common operations on a generated vault
```

CI runs the tests on Ubuntu (Neovim 0.10, 0.11, nightly) and macOS, with and without
ripgrep, plus lint, type check, docs freshness, and (weekly) Emacs fixture drift.

## Commit messages

This project uses [Conventional Commits](https://www.conventionalcommits.org/)
(`feat:`, `fix:`, `docs:`, `chore:`, `refactor:`, `test:`, `perf:`; add `!` or a
`BREAKING CHANGE:` footer for breaking changes). Releases, version numbers, and
`CHANGELOG.md` entries are generated by release-please from these messages, so do
not edit released CHANGELOG sections by hand; `feat` and `fix` commits show up in
the release notes.

## API docs

`doc/denote-api.txt` is generated from the LuaCATS annotations in `lua/denote/`.
The user guide `doc/denote.txt` is written by hand. After changing `---` doc comments, run:

```sh
cargo install --git https://github.com/mrcjkb/vimcats --tag v1.2.0 --features=cli --locked
make docs            # or: make docs VIMCATS=/path/to/vimcats
```

and commit the result; CI fails if the committed docs are stale. Use single
quotes for string-literal types (`---@param kind 'org'|'markdown'`), one
`---@return` per return value, and wrap module intros in `---@brief [[ ... ]]`.

## Emacs compatibility fixtures

Run `make fixtures` when you change naming, front matter, or link code, or to check a
new Denote release. It needs Emacs 28+ and network access the first time. Denote is
installed into `.cache/emacs-fixtures/` (delete that folder to upgrade), never into
`~/.emacs.d`. Commit the regenerated `tests/fixtures/emacs/denote.json` together with any
denote.nvim change it needs. Never edit the fixture by hand. If denote.nvim should
deliberately differ from Emacs, add an entry with a reason to `KNOWN_DIFFERENCES` in
`tests/spec/emacs_parity_spec.lua` rather than loosening a comparison.
