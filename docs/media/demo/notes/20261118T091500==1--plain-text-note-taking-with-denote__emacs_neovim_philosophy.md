Denote avoids proprietary databases and rigid folder trees. Every note is a
plain-text file whose filename carries its identifier, optional signature,
title, and keywords.

## Why filenames matter

- Future-proof: readable from any shell, grep, or editor.
- Immutable links: references point only to the timestamp identifier.
- Cross-format: Markdown and Org notes live side by side.
